# App Review notes

- **No account needed.** Lumi has no sign-in, subscriptions, ads or in-app purchases. Everything is free.
- **On-device.** Editing, upscaling, colorizing and object removal run locally with bundled Core ML models; no content leaves the device.
- **Permissions:** camera (Camera tab), microphone (video recording), photo library add-only (saving results). Photos are chosen with the system picker.
- **Models and open-source credits** are listed in Settings → Credits and at the public credits page (website/credits.html). Models: LaMa (Apache-2.0), Real-ESRGAN (BSD-3), SIGGRAPH17 colorization (BSD-2/MIT).
- **Test steps:** open Editor → pick any photo → try Adjust, Filter, Remove (brush over an object, tap Remove), Cutout, Enhance. Camera tab needs a physical device.
- **Apple Intelligence features** (when added) are optional and hidden on devices without support.
